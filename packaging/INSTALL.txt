Bad North Multiplayer (test build)
==================================

INSTALL
1. In Steam, right-click Bad North > Manage > Browse local files.
   (Usually C:\Program Files (x86)\Steam\steamapps\common\BadNorth)
2. Extract everything in this zip into that folder, so that winhttp.dll and the
   BepInEx folder sit next to BadNorth.exe.
3. Start Bad North from Steam as normal. A "Multiplayer" button appears in the
   top-right corner.

Make sure the Steam overlay is enabled (Steam > Settings > In Game), or the
invite button can't open.

PLAYING
- Host: click Multiplayer > Host game > Invite friend, pick your friend, then
  start or continue a campaign and go into a battle. You are the defender.
- Friend: accept the invite in Steam (the game starts or joins automatically).
  You are the mastermind: open the Multiplayer window and press
  "Launch next wave" to send the next Viking wave at the host.
- While a mastermind is connected, the host's waves only come when the
  mastermind launches them (the host can turn that off in the window).

Both players need the same mod version. The window says so if they don't match.

UNINSTALL
Delete winhttp.dll, doorstop_config.ini, .doorstop_version and the BepInEx folder
from the game folder.

PROBLEMS
Send BepInEx\LogOutput.log from the game folder.
